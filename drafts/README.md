# Drafts

Dated snapshots of the geothermal research paper, one per working session that actually moved the paper.

**Provenance note:** the three drafts in this folder were all authored during working sessions on 2026-09-27, as part of an iterative audit process (draft → audit → revision → re-audit → compression). They were preserved in the working-session record at the time but were not committed to this repository contemporaneously. They are being added to the repository later, as this provenance note explains, to preserve the authentic draft chain rather than to represent them as committed on 2026-09-27 — the filename dates reflect when each draft was actually written, not when the file was added to version control. No draft's prose was corrected, improved, or cleaned up when it was transcribed into this folder; each is preserved exactly as it existed at that stage, including whatever gaps or issues it had at the time (for example, draft 1 has no citations or References section — that gap is itself part of the authentic record, later closed in draft 2).

- `2026-09-27-geothermal-paper-draft-1.md` — the original full draft, before any citations were added, used for the first audit pass.
- `2026-09-27-geothermal-paper-draft-2.md` — the revised draft with in-text citations and a References list added, along with an explicit response to the strongest objection to the recommendation, used for the second audit pass.
- `2026-09-27-geothermal-paper-draft-3.md` — the compressed draft, cut to fit the assignment's four-page limit, used for the final compression audit.
- `2026-10-05-geothermal-paper-draft-4.md` — the post-Stauffer-feedback version: the Recommendation's break-even trigger addressed, References given URLs and retrieval dates, and Figure 1 repointed to its relocated path at repo-root `figures/`. This snapshot was captured contemporaneously from the working/master paper on the date in its filename rather than reconstructed afterward.

The version in `docs/decisions/hawaii-geothermal-paper.md` remains the working/master copy of the paper going forward; draft 4 is a point-in-time snapshot of it, not a replacement for it.
